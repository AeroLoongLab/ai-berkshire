## 第 1.1.1 节的现金流量表对账（本次研究的方法论要点）

两个独立信源给出看似矛盾的现金流量表数字：

- 雪球测算：购建固定资产 **−1.876 亿美元**（毛资本开支）
- 格隆汇整理的中期现金流量表：投资活动净额 **−4.34 亿港元 = −0.556 亿美元**

用格隆汇的三分项做闭合检验，两者自洽：

```
期初 39.81 + 经营 (−24.94) + 投资 (−4.34) + 融资 (+62.08) + 汇率 (+0.40) = 73.00 亿港元 ✓
经营 −24.94 亿港元 = −3.197 亿美元 ✓ 与独立源"−3.181 亿美元"吻合
差额 1.833 亿美元 ≈ FVTPL 金融资产净减少 1.610 亿美元（赎回收益冲抵资本开支）✓
现金净增 4.037 亿美元 = 期末 (930.905+0.752) − 期初 (507.621+20.377) ✓
```

**结论：−1.876 亿美元是毛资本开支，−0.556 亿美元是投资活动净额。真实月均总现金消耗（经营+资本开支，扣融资）是 6,130 万美元/月，即年化 7.36 亿美元。**

**这个对账改变了两条结论**：现金跑道从 3.4 年缩短到 2.9 年；并发现公司资本强度从"轻资产软件"突变为"重资产算力生意"（2025 全年设备采购 92 万美元 → 2026H1 1.876 亿美元，204 倍）。
